# 开服工坊使用说明

## 第一次运行

1. 将便携ZIP完整解压到可写目录，在Windows运行ServerWorkbench.exe。
2. 需要.NET Framework4.8。Windows11已有4.8.1时不需要降级；旧Windows需SP1和相应系统补丁。不能启动时先查看“启动检查.cmd”。
3. 数据默认保存在旁边Data；无法写入时会要求选择其他目录。运行期间不要手动移动Data。

## 创建服务器

“创建服务器 → 游戏预设”中选择类型，读取官方版本。Fabric/Forge还需读取加载器版本。Minecraft需要自行勾选EULA，默认内存2GB；端口冲突时更换端口。“服务器存放目录”可选择父目录，创建时在其下面建立独立实例子目录；留空使用默认 Data/Instances。每个实例可以选择不同磁盘。已存在实例的目录在启动配置中只读显示，不会因编辑配置而直接移动存档。仅 Minecraft 显示 EULA 协议区域。点击创建，观察进度；成功后回首页启动。

Minecraft自动安装面向1.16.5及之后的可识别正式版本。Forge需要在Windows运行官方安装器，期间要下载依赖。Terraria提供官网当前专服，并从固定微软官方 MSI 校验、提取实例私有 XNA/VC/DirectX 依赖，不安装系统组件。tModLoader选择稳定发布，按其声明准备精确私有 .NET，再用保留的官方 shell 同步启动。

旧Windows可能无法运行所选游戏或Java/.NET。请提供兼容的已有运行时或历史游戏包；软件不会靠安装最新版来假装解决兼容问题。

## 添加其他游戏

“通用导入”接受HTTPS文件直链、ZIP、目录、EXE、BAT/CMD、可执行JAR。先分析内容，再选入口，补全配置。目录与文件复制到独立实例，不修改源文件。

启动入口、工作目录、Mod和存档路径都使用相对于实例目录的路径。参数**每行一个**，无需手动加引号；环境变量每行`名称=值`。Java模式会自动添加内存参数及`-jar`。只有具备明确运行时信息时才能自动准备环境。

导入不执行包内安装器。网页链接、登录页、RAR/7z或Linux专用程序不能直接开服。请先通过官方方式获取Windows专服目录，再导入。

BAT/CMD经过cmd.exe运行，首版拒绝其路径和附加参数中的shell特殊字符。复杂命令写进你自己的启动脚本，或优先直接选择EXE/JAR。

## 资源监视与关服

首页显示CPU、内存与运行时长，曲线每3秒采样、最多显示最近9分钟。CPU为整机CPU能力的占比，Windows进程组包含启动脚本和游戏子进程。读数失败显示不可用，不视为服务器负载为零。

- **保存 / 回档点**：请求保存，等待游戏的完成日志，然后复制世界文件。Minecraft复制期间暂停自动保存，结束后恢复。
- **保存并关服**：发送正常退出命令，等待保存并退出，再生成世界回档点。预设Minecraft使用stop，Terraria/tModLoader先确认 save 的顺序应答与新世界写入，再使用 exit。30秒未退出时提示，不会自动转为强杀。
- **紧急关服 · 不保存**：跳过新的保存命令。Terraria使用exit-nosave，超时终止进程组；Minecraft直接终止进程组。游戏此前写入的自动保存不会被撤销；正在进行的保存也可能已写入部分内容。

托盘菜单另有“紧急结束全部服务器”，便于其他任务窗口打开时使用。它直接结束本软件管理的进程组，不发送保存命令。

## 最近两次存档与回档

游戏预设默认每5分钟请求保存并生成回档点。可在启动配置调整分钟数，0为关闭。检测到可识别的游戏保存完成日志时，也会触发确认保存和快照；不能识别的游戏自动保存不承诺被备份。

只有复制成功的回档点才轮换，始终保留最近两份。下载、保存确认或复制失败时不会删掉原有两份。首次开服还没有完成保存时，列表为空是正常的。

到“备份与恢复 → 最近两次存档”选择时间点：先停服；若要放弃未保存进度，先使用紧急关服。恢复前自动生成当前完整实例备份，然后替换配置的世界目录，避免残留较新的区块文件。Mod和其他配置不会跟随世界回档。

自定义游戏需要配置保存命令、可靠的保存完成日志正则，以及世界目录/文件列表。没有保存协议时，不能保证运行中复制的一致性；使用正常关服后的存档备份。世界目录必须在实例内部，不能设置整个实例根目录。

## Mod与完整备份

Fabric/Forge可在线搜索Modrinth并选择版本。软件递归处理必需依赖和声明冲突，变更前要求停服并备份。未声明的游戏内部冲突仍需看启动日志。客户端要求安装的Mod也必须同步给朋友。

本地支持JAR、tmod、目录和tModLoader的enabled.json。tmod读取内部名称，无法确认时要求补充。原版Minecraft与原版Terraria不加载模组。禁用通过移出加载目录实现，tModLoader还会维护enabled.json。

“完整实例备份”包含世界、Mod、配置和实例记录。它与仅保留两份的世界回档点独立，不自动删除。共享运行时不重复打包；恢复后可能需要重新选择环境。

## 联机和退出

先在本机连接127.0.0.1，再让局域网朋友使用网卡IPv4。异地可以使用公网端口转发、虚拟组网或“联机指引 → frp 内网穿透”。frp 需要自己的可信公网中转节点；软件不会凭空提供公网 IP。准备组件、填写节点地址/控制端口/朋友端口、证书中的名称、CA 公钥证书和 Token，游戏就绪后点击启动穿透。节点只确认注册时，不代表公网已经打通。完整步骤见 [内网穿透](内网穿透.md)。

关闭主窗口会进入托盘继续开服。真正退出使用托盘菜单，会等待正常停服；超时可取消退出或明确强制结束。不要用关闭窗口来假定已经关服。


## 独立目录和旧系统路径

实例文件可在创建时放到所选父目录；中央 Data 仍保存实例索引、共享运行时、完整备份与两份回档点，不要只移动其中一个目录。外部实例含管理身份标记，软件拒绝覆盖已有其他内容或删除父目录。恢复会保留当前存放路径。游戏自身、Java、BAT 和旧 Windows 的长路径支持不同，建议选择简短路径；中文和空格路径与 shell 特殊字符的限制仍需区分。
