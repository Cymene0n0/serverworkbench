## 本轮修复

- 创建窗口增加服务器存放父目录；预设和通用导入均创建独立子目录，留空保持默认。既有实例路径只读；复制实例清除旧绝对位置，避免覆盖源目录。
- 只有 Minecraft 预设显示协议行、复选框和链接；Terraria/tModLoader 切换时隐藏整行并清空勾选。
- 表单先设 96 DPI 基准再启用缩放，并限制在工作区；动态页面按当前 DPI 缩放一次，字段标题与选择器按钮列按内容布局，修复文字裁切、切页尺寸跳变、提示输入框覆盖和控件释放；资源读取错误显示不可用。
- 以挂起启动、先加入 Windows Job、再恢复执行的方式托管进程组；限制标准句柄继承，处理 BAT 先退出、准备运行时期间紧急取消与异常退出。
- Forge 移除交互 pause 并保留原脚本、Java 错误码及私有 PATH；tModLoader 移除 start 分离启动，保留官方 shell，预先准备精确私有 .NET。
- Java 明确 UTF-8 输入输出属性；Terraria 系列 Windows stdin 使用 UTF-16LE 无 BOM。预设保存使用同步 save 后的只读 version 顺序应答、新 .wld 哈希和错误检查；正常退出后再捕获世界，不将“开始保存”当完成。
- 保存失败、复制期间变动、损坏/残缺 ZIP 不轮换原有有效回档点；回档前完整备份；紧急路径不发送 save/stop/version。
- Terraria 新安装从固定微软签名 MSI 下载并校验 hash，只读提取白名单私有 XNA/VC/DirectX DLL；不运行 MSI 安装、不改 GAC、PATH 或系统组件。
- build.ps1 支持项目内 Windows SDK，打包只更新发行文件、保留现有 Data/settings/备份；干净 ZIP 不包含测试世界或用户数据，源码包排除 SDK、缓存、bin/obj。
